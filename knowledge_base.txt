<system-metadata>
The CommerceIQ Compute Platform (CCP) is a standardized ETL platform built on Databricks that transforms large-scale ecommerce data into clean, structured datasets. It abstracts infrastructure complexities and simplifies pipeline creation, allowing developers to process raw data in bulk on scheduled intervals. To apply configuration changes, developers must “link” their Git branch to the CCP backend—this ensures the backend reflects the latest commit, as changes in Git aren’t auto-synced. Environments are mapped to branches: feature/develop to beta (for development), release to QA (for validation), and master to prod (for live workloads). Linking can be automated via Bitbucket Pipelines for consistency and traceability, or done manually through a POST API in special cases. CCP uses configuration variables (STRING, NUMBER, DATETIME) declared in YAML at module/workflow/runtime levels to make workflows reusable and dynamic. Variables follow a scope hierarchy, and best practices include naming them descriptively, providing defaults, documenting their purpose, and ensuring consistent typing.
